## 1. Словари (dict)

Словарь хранит пары «ключ → значение» и заменяет кучу отдельных переменных вроде `num_of_warn`, `num_of_info`. Ключ должен быть неизменяемым (строка, число, кортеж), значение — любое.

```python
counts = {}                    # пустой словарь
counts = {"INFO": 3, "ERROR": 1}

counts["WARN"] = 2             # добавить или перезаписать
print(counts["INFO"])          # 3
print(counts["DEBUG"])         # KeyError: такого ключа нет
```

Безопасное чтение — через `get` со значением по умолчанию и проверку `in`:

```python
counts.get("DEBUG", 0)         # 0, без ошибки

if "ERROR" in counts:          # проверка наличия ключа
    print("ошибки есть")
```

**Главный приём дня 3 — подсчёт.** Одна строка вместо цепочки `if/elif`, и она работает для любых уровней, даже заранее неизвестных:

```python
counts = {}
for line in sys.stdin:
    parts = line.split()
    if len(parts) < 3:
        continue
    level = parts[2]
    counts[level] = counts.get(level, 0) + 1
```

Перебор словаря:

```python
for key in counts:                  # только ключи
    print(key)

for value in counts.values():       # только значения
    print(value)

for key, value in counts.items():   # пары — самый частый вариант
    print(f"{key}: {value}")
```

Полезное:

- `len(counts)` — число ключей;
- `sum(counts.values())` — сумма всех значений;
- с Python 3.7 словарь помнит порядок добавления ключей.

## 2. Сортировка и топ-N

`sorted()` возвращает новый отсортированный список и ничего не меняет в исходных данных. Ключевые параметры — `key` (по чему сортировать) и `reverse=True` (по убыванию).

```python
sorted([3, 1, 2])                        # [1, 2, 3]
sorted([3, 1, 2], reverse=True)          # [3, 2, 1]
sorted(["b", "A", "c"], key=str.lower)   # без учёта регистра
```

Словарь сам по себе не сортируется, сортируют его пары из `items()`. Каждая пара — кортеж `(ключ, значение)`, поэтому значение берётся как `pair[1]`. Функцию, которая его достаёт, передаём в `key`:

```python
counts = {"INFO": 7, "ERROR": 12, "WARN": 3}

def by_count(pair):
    return pair[1]

for level, n in sorted(counts.items(), key=by_count, reverse=True):
    print(f"{level}: {n}")
# ERROR: 12
# INFO: 7
# WARN: 3
```

Обратите внимание: в `key=by_count` функция передаётся **без скобок**. Мы не вызываем её сами, а отдаём `sorted`, и он вызовет её для каждой пары.

> Позже вы встретите `lambda` — безымянную функцию в одну строку, которой часто пишут такие `key`. Пока везде используем обычную функцию через `def`: так нагляднее, что именно происходит.

**Топ-N** — это срез отсортированного списка: `[:5]` берёт первые пять элементов, и срез не падает, если элементов меньше.

```python
top5 = sorted(counts.items(), key=by_count, reverse=True)[:5]
```

Не путайте с `list.sort()`: он сортирует список на месте и возвращает `None`, поэтому `x = mylist.sort()` даст `x = None`.

## 3. Множества (set)

Множество хранит только уникальные значения: повторное добавление ничего не меняет. Порядок элементов не сохраняется, поэтому для вывода множество сортируют.

```python
ips = set()              # пустое множество; {} — это пустой СЛОВАРЬ
ips.add("1.2.3.4")
ips.add("5.6.7.8")
ips.add("1.2.3.4")       # повтор — ничего не изменится

print(len(ips))          # 2
print("1.2.3.4" in ips)  # True, проверка очень быстрая

for ip in sorted(ips):
    print(ip)
```

Превратить список в множество — быстрый способ убрать дубли: `set(["a", "b", "a"])` даёт `{"a", "b"}`.

Операции над множествами пригодятся, чтобы сравнить два набора, например IP за два дня:

| Операция    | Запись   | Результат              |
| ----------- | -------- | ---------------------- |
| Объединение | `a \| b` | все элементы из обоих  |
| Пересечение | `a & b`  | только общие           |
| Разность    | `a - b`  | есть в `a`, нет в `b`  |

Когда что выбирать: нужен только факт «встречалось или нет» — `set`; нужно ещё и «сколько раз» — `dict`.

## 4. Разбор строк лога

В дне 3 строки сложнее, чем `дата время УРОВЕНЬ`, поэтому одного `split()` мало. Пять инструментов покрывают все задачи.

### `split(maxsplit=N)`

Делит не больше N раз, остаток остаётся целым. Так сообщение не разваливается на слова:

```python
line = "Oct 02 14:08:42 mail sshd-session[1886]: error: mm_reap: child"
parts = line.split(maxsplit=5)
# ['Oct', '02', '14:08:42', 'mail', 'sshd-session[1886]:', 'error: mm_reap: child']
message = parts[5]
```

### `partition(sep)`

Делит по первому вхождению разделителя на три части и никогда не падает:

```python
proc = "postfix/smtpd[94240]:"
name, sep, rest = proc.partition("[")
# name = 'postfix/smtpd'; если '[' нет — name = вся строка, sep = ''
```

### `rstrip(chars)` / `strip()`

Убирают символы по краям: `"systemd:".rstrip(":")` даёт `"systemd"`. Без аргумента убирают пробелы и `\n`.

### `in` и `find()`

Поиск подстроки. `"error" in message.lower()` отвечает «да/нет»; `s.find("x")` возвращает позицию или `-1`.

### Срезы

Вырезать кусок между найденными позициями:

```python
line = "connect from unknown[46.151.182.181]"
start = line.find("[") + 1
end = line.find("]")
ip = line[start:end]     # '46.151.182.181'
```

Порядок проверок прежний: сначала убедиться, что нужная часть есть (длина `parts`, результат `find` не `-1`), потом её брать.

## 5. Функции

Функция — именованный кусок кода, который получает данные через параметры и отдаёт результат через `return`. Хорошая функция делает одно дело, не печатает и не читает `stdin` сама, а возвращает значение.

```python
def get_process(proc_field):
    name, _, _ = proc_field.partition("[")
    return name.rstrip(":")

print(get_process("postfix/smtpd[94240]:"))  # postfix/smtpd
```

### Несколько значений

Возвращают кортежем и сразу распаковывают:

```python
def parse_line(line):
    parts = line.split(maxsplit=5)
    if len(parts) < 6:
        return None              # «строка не подходит»
    return parts[4], parts[5]    # кортеж (process, message)

for line in sys.stdin:
    result = parse_line(line)
    if result is None:
        continue
    process, message = result
```

### `None`

`None` — обычный способ сказать «результата нет». Проверяют его через `is None`, а не `== None`. Функция без `return` тоже возвращает `None`, это частая причина ошибок вида `'NoneType' object is not subscriptable`.

### Область видимости

Переменные, созданные внутри функции, снаружи не видны, и наоборот: функция не должна менять чужие переменные. Всё, что ей нужно, передавайте параметрами, всё, что она вычислила, возвращайте.

### Значение по умолчанию

Делает параметр необязательным:

```python
def by_count(pair):
    return pair[1]

def top(counts, n=5):
    return sorted(counts.items(), key=by_count, reverse=True)[:n]

top(counts)      # топ-5
top(counts, 3)   # топ-3
```

## 6. Аргументы командной строки и файлы

### `sys.argv`

Список строк из командной строки. Нулевой элемент — имя скрипта, дальше аргументы по порядку. Все элементы — строки, числа нужно переводить через `int()`.

```console
$ python3 d3_06.py data/syslog.txt -n 3
```

```python
sys.argv == ['d3_06.py', 'data/syslog.txt', '-n', '3']
```

Прежде чем брать `sys.argv[1]`, проверьте длину списка — та же ловушка с индексом, что и с `parts`:

```python
if len(sys.argv) > 1:
    filename = sys.argv[1]
else:
    filename = None      # читать stdin
```

### Чтение файла

Через `with open(...)`: файл закроется сам, даже если внутри случится ошибка. Файл перебирается по строкам так же, как `sys.stdin`:

```python
with open(filename, encoding="utf-8") as f:
    for line in f:
        print(line.rstrip())
```

Чтобы одна функция работала и с файлом, и с `stdin`, передавайте ей сам источник строк:

```python
def count(lines):
    counts = {}
    for line in lines:
        ...              # разбор и подсчёт
    return counts

if filename:
    with open(filename, encoding="utf-8") as f:
        counts = count(f)
else:
    counts = count(sys.stdin)
```

### Если файла нет

`open` бросает `FileNotFoundError`. Ловите его и завершайтесь так же, как в задаче 13:

```python
try:
    f = open(filename, encoding="utf-8")
except FileNotFoundError:
    print(f"файл не найден: {filename}", file=sys.stderr)
    sys.exit(1)

with f:
    counts = count(f)
```

Другие частые исключения при работе с файлами:

- `PermissionError` — нет прав, например `/var/log/syslog` без `sudo`;
- `IsADirectoryError` — передали папку вместо файла.
