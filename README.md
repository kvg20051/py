# Python за неделю — подготовка к собеседованию

Цель: уверенно решать практические задачи на Python (обработка текста и логов,
подсчёты, группировка) на собеседовании в поддержку внутренних ИТ-сервисов.

## План

| Дата        | Тема                                                        | Папка  |
|-------------|-------------------------------------------------------------|--------|
| 8 окт, ср   | Синтаксис, типы, if, циклы, функции, ввод/вывод             | day1/  |
| 9 окт, чт   | Строки и списки, срезы, list comprehension                  | day2/  |
| 10 окт, пт  | Словари и множества, подсчёт и группировка                  | day3/  |
| 11 окт, сб  | Файлы, логи, Counter, defaultdict, sorted(key=)             | day4/  |
| 12 окт, вс  | re, json, datetime, исключения                              | day5/  |
| 13 окт, пн  | Задачи собеседований: хеш-таблицы, два указателя, сложность | day6/  |
| 14 окт, вт  | Пробные собеседования                                       | day7/  |

Распорядок дня (8 ч): теория 1,5 ч → задачи 5 ч → разбор и повторение 1,5 ч.

## Как работать

```bash
cd ~/python-week/day1
less THEORY.md               # теория дня
vim d1_01.py                 # условие задачи — в начале файла
python3 d1_01.py             # запуск
python3 d1_14.py < data/test.log

cd ~/python-week
python3 check.py 1           # проверить все задачи дня 1
python3 check.py 1 13        # проверить одну задачу
```

Решения присылайте в чат — разберу ошибки и покажу идиоматичный вариант.

## Настройка vim

```vim
set expandtab tabstop=4 shiftwidth=4 autoindent
syntax on
```

## Полезное

- `python3 -i file.py` — запустить и остаться в интерпретаторе с переменными
- `help(str.split)` — справка прямо в интерпретаторе
- `python3 -m py_compile file.py` — проверить синтаксис
