# День 2. Строки, списки, срезы, list comprehension

Цель дня: уверенно разбирать одну строку лога на поля и работать со
списком строк целиком — фильтровать, сортировать, брать «хвост» и «голову».
Все задачи — на реальном формате nginx (`data/nginx.log`).

Пробуйте каждый пример в интерактивном `python3`.

## 1. Строки

```python
s = "GET /api/users HTTP/1.1"
len(s)            # 23
s[0]              # 'G'  — индекс с нуля
s[-1]             # '1'  — с конца
s[0] = "P"        # TypeError: строка неизменяема, создавайте новую

"api" in s                    # True — поиск подстроки
s.startswith("GET")           # True
s.endswith(".php")            # False
s.find("/")                   # 4  (нет — -1)
s.count("/")                  # 3

s.lower(), s.upper()
"  текст \n".strip()          # 'текст' — пробелы и \n по краям
'"GET'.lstrip('"')            # 'GET'  — убрать конкретные символы слева
"[07/Oct".strip("[")          # '07/Oct'
s.replace("HTTP/1.1", "")     # замена (возвращает новую строку)

"404".isdigit()               # True — перед int() удобно проверять
"abc".isalpha()               # True
```

## 2. split и join — мост между строкой и списком

```python
line = "10.0.0.15 - - [07/Oct/2026:19:00:05 +0300] \"GET /api/users HTTP/1.1\" 200 842"
parts = line.split()          # по любым пробелам, лишние пустые не создаются
parts[0]                      # '10.0.0.15'
parts[-1]                     # '842'

"192.168.1.101".split(".")    # ['192', '168', '1', '101']
"a,b,,c".split(",")           # ['a', 'b', '', 'c'] — с явным разделителем пустые остаются
"k=v=w".split("=", 1)         # ['k', 'v=w']  — не больше одного разреза

".".join(["192", "168", "1", "xxx"])   # '192.168.1.xxx'
", ".join(ips)                          # список строк → одна строка
" ".join(str(n) for n in [1, 2, 3])    # join принимает только строки

path, _, query = "/search?q=linux".partition("?")   # '/search', '?', 'q=linux'
```

Поля строки nginx после `split()`:

| Индекс | Пример                  | Что это               | Как очистить     |
|--------|-------------------------|-----------------------|------------------|
| 0      | `10.0.0.15`             | IP клиента            | —                |
| 3      | `[07/Oct/2026:19:00:05` | время                 | `[1:]`           |
| 5      | `"GET`                  | метод                 | `[1:]`           |
| 6      | `/api/users`            | путь                  | —                |
| 8      | `200`                   | код ответа            | `int()`          |
| 9      | `842`                   | размер ответа, байт   | `int()`          |

Индексы считаются только после проверки `len(parts) >= 10` — правило из дня 1.

## 3. Срезы `[start:stop:step]`

Работают одинаково для строк и списков. `stop` не включается, выход за
границы не вызывает ошибку.

```python
s = "[07/Oct/2026:19:00:05"
s[1:]          # '07/Oct/2026:19:00:05'  — без первого символа
s[1:3]         # '07'
s[-8:]         # '19:00:05'  — последние 8
s[:-3]         # всё, кроме последних трёх
s[::-1]        # строка задом наперёд
s[::2]         # каждый второй символ

lines[:10]     # head -n 10
lines[-10:]    # tail -n 10
lines[10:20]   # строки 11–20
lines[::5]     # каждая пятая
copy = lines[:]   # копия списка
```

## 4. Списки

```python
codes = []                  # пустой список
codes.append(200)           # в конец
codes.extend([404, 500])    # несколько сразу
codes.insert(0, 301)        # по индексу
codes.pop()                 # снять последний (вернёт его)
codes.remove(404)           # удалить первое вхождение значения
codes.index(200)            # позиция значения
codes.count(200)            # сколько раз встречается
500 in codes                # проверка — перебирает весь список

len(codes), sum(codes), min(codes), max(codes)

sorted(codes)               # НОВЫЙ отсортированный список
sorted(codes, reverse=True)
codes.sort()                # сортирует НА МЕСТЕ, возвращает None
codes.reverse()             # переворот на месте

for i, line in enumerate(lines):        # индекс + значение
    ...
for ip, code in zip(ips, codes):        # два списка параллельно
    ...
```

**Ловушка:** `b = a` не копирует список, а даёт второе имя тому же объекту.
Изменение через `b` видно в `a`. Копия — `b = a[:]` или `b = list(a)`.

### Кортежи и сортировка по нескольким полям

Кортеж — неизменяемый список: `(842, "/api/users")`. Списки кортежей
сортируются по первому элементу, при равенстве — по второму:

```python
reqs = [(842, "/api/users"), (15432, "/favicon.ico"), (615, "/")]
sorted(reqs, reverse=True)[:2]   # два самых тяжёлых ответа
for size, path in reqs:          # распаковка в цикле
    print(path, size)
```

## 5. List comprehension

Короткая запись «пройти, отфильтровать, преобразовать» в один список.

```python
# обычный цикл
errors = []
for line in lines:
    parts = line.split()
    if int(parts[8]) >= 400:
        errors.append(line)

# то же самое
errors = [line for line in lines if int(line.split()[8]) >= 400]

sizes = [int(p[9]) for p in rows]                  # преобразование
ips = [p[0] for p in rows if p[8].startswith("5")] # фильтр + преобразование
lines = [l.rstrip("\n") for l in sys.stdin if l.strip()]   # чтение без пустых строк

any("wp-login" in p for p in paths)   # есть ли хоть одно совпадение
all(c.isdigit() for c in "404")        # все ли символы цифры
```

Когда comprehension не нужен: если внутри больше одного `if` или нужно
печатать, обычный цикл читается лучше. Comprehension собирает список,
а не выполняет действия.

## 6. Весь stdin в список

Для задач «последние N строк», «строка до и после» или повторного прохода
данные нужны целиком:

```python
lines = sys.stdin.read().splitlines()   # список строк без \n
rows = [l.split() for l in lines if l.strip()]
rows = [p for p in rows if len(p) >= 10]  # отсеять битые строки
```

Для больших логов (гигабайты) так не делают — читают построчно, как в
дне 1. На собеседовании стоит сказать об этом вслух.
